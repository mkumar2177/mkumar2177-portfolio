# Khalid Umar Portfolio (React + Vite + Tailwind)

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build into dist/
```
- Content lives in `src/data.ts`. Set `linkedin` there to show the LinkedIn link.
- Put your resume at `public/Mohd_Khalid_Umar_Resume.pdf`.
- Deploy: push to GitHub, then import the repo in Vercel (framework: Vite). For GitHub Pages, upload `dist/` or use a Pages workflow.
